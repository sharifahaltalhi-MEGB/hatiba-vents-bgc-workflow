# # BGC Analysis Workflow – Red Sea Hydrothermal Vent MAGs

This repository contains scripts used to analyze biosynthetic gene clusters (BGCs) from metagenome-assembled genomes (MAGs) of the Hatiba Mons hydrothermal vent system.

Associated manuscript:  
**Genetic insights into biosynthetic diversity and novelty in Red Sea hydrothermal vent microbiomes**

---

## Overview

This workflow performs:

- Extraction of BGCs from antiSMASH outputs  
- Clustering into gene cluster families (GCFs) using BiG-SCAPE  
- Global novelty assessment using BiG-SLiCE  
- Integration of annotations and metadata  
- Ecological and statistical analyses  

---
## Input data

This workflow requires the following input files:

- antiSMASH v8 output (.gbk files) organized per genome in a recursive directory structure  
  Obtained by running antiSMASH v8 on the MAG-associated contigs used in this study.

- bgc_level_antismash_v8_with_genome_metadata.csv  
  Generated from parsed antiSMASH results and merged with genome and sample metadata.

- mix_clustering_c0.7_v2.tsv  
  Generated by BiG-SCAPE v2 clustering at cutoff 0.7.

- record_annotations.tsv  
  Generated from the BiG-SCAPE annotation output.

- global_features_matrix.tsv  
  External reference feature matrix used for BiG-SLiCE distance calculations against global BGC reference space.

Optional inputs:
- mibig_ids.txt  
  List of MiBIG BGC IDs extracted from BiG-SCAPE network outputs representing matches between Red Sea BGCs and reference MiBIG clusters.
- MAG_best_hits_with_products_le0.45_header.tsv  
  Generated from similarity filtering of Red Sea BGCs against MiBIG-linked results for functional role summarization.

## Workflow

Run scripts in the following order:

---

### 1. Parse antiSMASH output
```
01_parse_antismash_gbk.py
02_parse_antismash_summary.sh
```
Extracts BGC metadata from antiSMASH `.gbk` region files.

---

### 2. Cluster BGCs (BiG-SCAPE)
```
03_run_bigscape_cutoff0.7.sh
03b_run_bigscape_cutoff0.5.sh
```
Groups BGCs into gene cluster families (GCFs).

---
#### Global novelty framework

To assess global biosynthetic novelty, Red Sea BGCs were compared against a previously generated BiG-SLiCE v1.1.1 reference dataset comprising approximately 1.2 million BGCs from RefSeq, GenBank, and MIBiG. Numerical feature matrices were generated from BiG-SLiCE results using the `extract_features_matrix.py` utility provided by the BiG-SLiCE authors (https://github.com/medema-group/bigslice/tree/master/misc/useful_scripts). For the Red Sea dataset, this script was adapted to preserve BGC names as row identifiers in the exported matrix. To ensure comparability between the Red Sea and reference datasets, only shared features were retained before downstream distance calculations, so that all distances were computed in the same feature space.
### 3. Compute novelty (BiG-SLiCE)
```
04_run_bigslice.sh
05_extract_redsea_features_matrix.py
05b_extract_bigslice_features_matrix.sh
06_calculate_bigslice_distance_matrix.py
06b_run_bigslice_distance_matrix.sh
07_summarize_novelty_threshold.py
07b_run_summarize_bigslice_novelty.sh
```
Encodes BGCs, computes distances to global reference space, and defines novelty (distance > 900) following the feature matrix framework described above.
---

### 4. Merge annotations
```
08_merge_bigscape_annotations.R
09_merge_bigscape_annotations_and_novelty.R
10_merge_family_assignments.R
17_prepare_novelty_merged_table.R
```
Combines antiSMASH output, BiG-SCAPE clustering, and BiG-SLiCE novelty.

---

### 5. Ecological and diversity analyses
```
11_beta_diversity_gcf_composition.R
12_summarize_shared_vs_habitat_specific_gcfs.R
13_define_stable_gcf_sets.R
14_merge_consistent_gcfs_with_annotations.R
15_plot_gcf_taxonomic_composition.R
16_compare_compact_vs_modular_by_habitat.R
```
Includes beta diversity, subsampling, habitat-specific GCF analysis, and taxonomic composition.

---

### 6. Novelty analyses
```
18_novelty_by_taxa.R
19_novelty_by_habitat.R
20_novelty_by_category.R
23_archaea_novelty_by_category.R
```
Evaluates novelty across taxa, habitat, and biosynthetic categories.

---

### 7. Lineage enrichment
```
21_lineage_enrichment_major_categories.R
```
Identifies lineage-associated enrichment of GCFs.

---

### 8. Visualization
```
22_plot_bgc_novelty_histogram.R
25_plot_mibig_functional_roles.R
```
Generates figures used in the manuscript.

---

### 9. MiBIG compound annotation
```
24_get_mibig_compounds.py
24b_run_mibig_compounds.slurm
```
Retrieves compound annotations for BGCs linked to MiBIG reference clusters.
